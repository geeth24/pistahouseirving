# Pista House Irving

The West Royal Lane restaurant website uses Next.js App Router, React, Tailwind CSS, and shadcn/ui. Run `bun install` and `bun run dev` to start it locally.

The dining menu lives in `lib/dining-menu.ts` and the catering menu in `lib/catering-menu.ts`. Guests can search both menus and email a catering selection. Online ordering provides current prices and availability.

Update restaurant contact and ordering links in `lib/restaurant.ts`. Theme colors, the wordmark treatment, typography, and motion settings are in `styles/globals.css`.
